# Glossary

Canonical domain vocabulary for the Dagent customization of Xagent.

## Language

**Agent**:
执行任务的智能体。

**Task**:
一次可追踪的执行任务。

**Memory**:
用户／智能体记忆。
_Avoid_: Knowledge Base、KB、RAG（这些不是 Memory 的别名）

**Knowledge Base (KB/RAG)**:
文档知识检索与 grounding，与 Memory 分开。
_Avoid_: Memory（不能用记忆存储代指知识库）

**Workspace**:
任务文件工作的隔离空间。

## Known Limitations and Deferred Work

Only the five terms above are confirmed. Open terminology questions live in
`CONTEXT.md`; add a definition here only when its meaning is settled.
